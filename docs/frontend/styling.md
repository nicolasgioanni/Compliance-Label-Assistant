# Styling

## CSS Entrypoints

Imported by `frontend/src/main.jsx`:

- `frontend/src/styles/index.css`
- `frontend/src/styles/components.css`

## Component Partials

`frontend/src/styles/components.css` imports:

- `frontend/src/styles/components/layout.css`
- `frontend/src/styles/components/forms-controls.css`
- `frontend/src/styles/components/queue.css`
- `frontend/src/styles/components/selected-workspace.css`
- `frontend/src/styles/components/status-results.css`
- `frontend/src/styles/components/dialogs-feedback.css`
- `frontend/src/styles/components/static-pages.css`
- `frontend/src/styles/components/skeleton.css`
- `frontend/src/styles/components/responsive.css`

## Build Processing

`frontend/postcss.config.cjs` enables Autoprefixer.

`frontend/vite.config.js` sets browser build targets.

## Style Responsibilities

- `frontend/src/styles/index.css`: global page variables, base typography tokens, page background, and root layout.
- `frontend/src/styles/components.css`: central import point for component style partials.
- Component partials: layout, controls, queue, selected workspace, status/result cards, dialogs, feedback, static pages, skeleton placeholders, and responsive behavior.
- `frontend/src/styles/components/static-pages.css`: shared static/informational page layout, headers, sections, cards, callouts, tables, documentation links, and landing-page informational panel styling.

## Notes

- Styling is CSS-only; no CSS-in-JS library is used.
- Content typography uses the local/system sans-serif stack declared in `--font-sans`; no remote font provider or bundled font files are used.
- Status class names are generated by `frontend/src/utils/statusStyles.js` and `frontend/src/utils/statusResolution.js`.
- Skeleton loading is CSS-only and uses existing colors, radii, and reduced-motion behavior. It is a UI placeholder only and does not imply progress percentages or completed verification results.
- Component docs do not document every CSS selector. Use CSS partial filenames to find styling by user interface area.
